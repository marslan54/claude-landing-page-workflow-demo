# AI Landing Page Workflow: demo

**Live page:** https://marslan54.github.io/claude-landing-page-workflow-demo/

A recorded run of a reusable Claude Code workflow. It takes a reference landing page, a brand guide and a short
brief, and four subagents analyse the layout, write on-brand copy, build the page and check it. An automated QA
gate runs 23 checks, and the finished page is packaged as a WordPress plugin. The page includes a one-minute
walkthrough video, the reference, the generated page and the full QA report.

This repository holds only the static demo page. The skills, subagents and scripts are in a private repository and
are available on request. The sample brand and reference page are fictional.
